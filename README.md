# FastAPI Task Management Service

**Проект:** Микросервис для управления задачами с использованием FastAPI, SQLAlchemy 2.0 и асинхронного подхода

## Особенности архитектуры

### 1. Чистая структура проекта

## 🏗 Структура проекта

```plaintext
.
├── database.py       # Настройки DB и ORM-модели
├── repository.py     # Слой работы с данными
├── schemas.py        # Pydantic-схемы
├── router.py         # Эндпоинты API
└── main.py           # Инициализация приложения
```

### 2. Ключевые технологии
- **FastAPI** с асинхронными эндпоинтами
- **SQLAlchemy 2.0** с async/await поддержкой
- **Pydantic v2** для валидации данных
- **Uvicorn** как ASGI-сервер
- **Docker** контейнеризация

## Установка и запуск

### Локальная разработка
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate    # Windows

pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Docker сборка
```
docker build -t task-service .
docker run -dp 8000:80 task-service
```

## Best Practices проекта

##### 1. Слоистая архитектура:
- Роутеры → Репозитории → Модели
- Четкое разделение ответственности

##### 2. Типизация:
- Аннотации типов для всех методов
- Отдельные схемы для запросов/ответов

##### 3. Логирование:
- Настроено в main.py
- Фиксирует ключевые события жизненного цикла

##### 4. Безопасность:
- Автоматическое управление сессиями БД
- Валидация всех входящих данных
